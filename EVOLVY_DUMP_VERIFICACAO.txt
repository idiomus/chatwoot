5. CORREÇÕES APLICADAS (16/01/2026)
================================================================================

5.1 Extensões de Arquivos
--------------------------------------------------------------------------------
Problema: Script de download salvava todos os arquivos como .bin
Solução: Renomeação baseada no mimetype do JSON original
Resultado: 15,559 arquivos renomeados para extensão correta

5.2 Mensagens de Conversas Importadas
--------------------------------------------------------------------------------
Problema: Erro "can't quote Contact" no bulk import de mensagens
Causa: Método determine_message_sender retornava objetos em vez de IDs
Solução: Extrair sender.class.name e sender.id para insert_all
Resultado: 2,458 conversas tiveram mensagens reimportadas com sucesso

5.3 Duplicatas de Download
--------------------------------------------------------------------------------
Problema: Downloads duplicados (mesmo arquivo com extensões diferentes)
Solução: Verificar att_ID.* (qualquer extensão) antes de baixar
Resultado: 17,490 arquivos .bin duplicados removidos

5.4 Importação Paralela de Attachments
--------------------------------------------------------------------------------
Problema: Importação sequencial muito lenta (~2 arquivos/segundo)
Solução: Task parallel com thread pool e ajuste de connection pool
Comando: rake evolvy:import_attachments_parallel THREADS=16
Resultado: 20,567 attachments importados em 3 horas (1.88 att/sec)
